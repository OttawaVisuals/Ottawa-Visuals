# Seed list of Transit Committee / Transit Commission meetings.
# One per line. You can paste either the full Meeting.aspx URL or just the GUID.
# Blank lines and lines starting with # are ignored.
#
# How to collect these (5-10 min, one time):
#   1. Open https://pub-ottawa.escribemeetings.com/ in your browser.
#   2. Use the committee filter / search for "Transit Committee" and
#      "Transit Commission" (the older name), and each year you care about.
#   3. Right-click each meeting -> Copy link, and paste it below.
# After that, the scraper handles all the PDF downloading/parsing unattended.
#
