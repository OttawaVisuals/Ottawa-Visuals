# Ottawa Ward Elections

**Page:** [`ottawa_ward_elections.html`](ottawa_ward_elections.html). Historical mayor results and council participation, 2010–2026 (2026 = unofficial City results, ward totals only).

**Read first:** [`SOURCE_RECONCILIATION.md`](SOURCE_RECONCILIATION.md) records the October 17, 2026 source audit, corrections, definitions and unresolved gaps.

| File | Purpose |
|---|---|
| `FetchOfficial2026.py` | Reads the City's official 2026 Statement of Votes Cast workbook (open.ottawa.ca item `28d0d0f0d4704ba295dd362a31c07aee`, created 2026-10-30) into `reconciliation/results_2026_official.json`. Ward totals only; identical to the unofficial feed on every race. `BuildWardData.py` prefers this file |
| `FetchResults2026.py` | Fetches the City's 2026 unofficial results feed (`app06.ottawa.ca/election/2026/results.xml` + `electionevent.xml`) into `reconciliation/results_2026.json`. Ward totals only: no polling-place detail and no mayor split by ward. Re-run after the City certifies or revises results |
| `ReconcileSources.py` | Downloads the four City-published workbooks, checks precinct/candidate/city controls, and creates normalized source data plus a field comparison |
| `reconciliation/source_results.json` | All extracted mayor/council candidate totals, source rows, city controls, unallocated special polls, hashes and provenance |
| `reconciliation/field_comparison.csv` | Every populated legacy input compared with the corresponding source field |
| `reconciliation/legacy_ward_results.csv` | Immutable pre-audit baseline; also retains the 2022 map's ward names |
| `reconciliation/legacy_population_estimates.csv` | Eight old population figures retained as unverified; not used by the page |
| `BuildWardData.py` | Builds the page datasets and CSV exports from the normalized source extract |
| `ward_results.csv` | 117 ward-year rows. `Mayor_Votes` / `Council_Votes` now consistently mean **valid candidate votes**. Separate `*_Ballots_Cast` fields preserve available ballot counts. Coverage/certification/source columns are essential. |
| `ward_data.json`, `mayor_history.json` | Generated page data, also embedded in the HTML for a standalone page |
| `Ottawa_Summary.csv` | Tab-separated citywide registered, ballot and valid-mayor-vote controls; unavailable ballots are blank |
| `Ottawa_Election_Wards_Only.json` | Simplified TopoJSON locator for the 24 wards used in 2022 |
| `Ottawa_Election_Map_2022.json`, `Ottawa_Election.json` | Supporting polling-subdivision geometry; not generated by the data builder |
| `ELECTORAL_DISTRICT*.json` | Supporting federal-boundary layers; not election-result inputs |
| `test_reconciliation.py` | Independent control totals, coverage, missing-data and generated-output checks |

## Rebuild from any working directory

```powershell
python -m pip install openpyxl xlrd
python Ottawa_Elections/ReconcileSources.py
python Ottawa_Elections/BuildWardData.py
python -m unittest discover -s Ottawa_Elections -p "test_*.py"
```

The importer caches original workbooks and metadata under the system temporary directory in `ottawa-election-reconciliation`. `--cache PATH` selects another cache; `--refresh` re-downloads. A source hash change stops the importer for review. The retained JSON supports rebuilding the page without network access or workbook readers. No spreadsheet is modified.

## Reading the page

- **Find and share:** search by ward name or number at the top (accents optional). Ward selection, year and map mode are preserved in the URL. On phones the list shows full ward names and the selected metric; tap a ward for candidate details and history.
- **Ballot turnout** is ballots cast / registered voters. Full ward figures are available in 2018 and 2022.
- **Valid council vote participation** is valid council votes / registered voters. It supports the older years but must not be called ballot turnout.
- **Candidate shares** use valid candidate votes for the same race and coverage.
- **Mayor ward-coded polls** omit citywide special polls after 2010. Complete citywide mayor totals include them. Ward poll leaders are not certified home-ward winners.
- **2010** is a City download whose metadata disclaims official status. Wards 7 and 15 lack council data; Ward 6 has a documented candidate detail/total conflict.
- **Geography:** earlier observations describe original ward numbers. The map shows 2022 boundaries as a locator. No historical values are invented for Ward 24, and no 2018–2022 ward changes are claimed without a spatial crosswalk.
- **Population:** the former All residents view is withheld because its eight population/under-18 estimates could not be verified during this audit.
