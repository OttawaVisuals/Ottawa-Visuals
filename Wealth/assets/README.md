# Wealth artwork — design 2

Approved direction: households and assets, matching the Energy illustrations'
navy/teal/amber palette, rounded outlines and white interiors.

Created with built-in image generation from the approved B concept board.
Exact production prompts are in `prompts.json`. Seven transparent PNG originals
remain in the Codex generated-images folder; these files are lossless WebP
conversions with transparency retained, without content edits or resizing.

- `households-assets.webp`: homepage card and report header.
- `distribution.webp`, `trend.webp`, `survey.webp`, `richest.webp`,
  `percentiles.webp`, `history.webp`: six report section labels.

These are decorative qualitative symbols, not measured data. Images have empty
alt text; adjacent text conveys the section meaning. Light image panels preserve
the navy edges across light, dark and colour-blind page themes.
